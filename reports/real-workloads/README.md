# Real-World Workload Profiling (TheAgentCompany)

> **Status: Work In Progress (Preparation & Preflight Verified; Full-Scale Trace Replay In Progress)**

This directory contains task manifests, adapter metadata, and coverage projections for evaluating adapter warmth vs. KV prefix reuse on realistic multi-turn agent trajectories from **TheAgentCompany**.

## Background & Motivation

Synthetic and controlled microbenchmarks evaluate isolated components (swap time and single-prompt prefix hits). However, realistic production agent workloads have:
- Multi-turn accumulated message histories.
- Tool observations and command outputs of varying lengths.
- Frequent context growth with varying prefix overlaps across turns.
- Interleaved tasks across diverse operational roles (coding, customer support, data querying, document extraction, summarization).

To evaluate locality in realistic conditions, we reconstruct 20 representative tasks across 5 functional agent roles from TheAgentCompany dataset.

## Role & Adapter Mapping (20-Task Workplace Suite)

## File Manifest & Artifacts

- [`theagentcompany_20tasks.json`](theagentcompany_20tasks.json): Source specification of the 20 selected tasks, their instruction summaries, source repository paths, and mapped roles/adapters.
- [`theagentcompany_20tasks_verified.json`](theagentcompany_20tasks_verified.json): Preflight-verified manifest generated by `scripts/workplace/verify_workplace_setup.py`, recording local trace file presence and source Git revision hash (`f9b1e9411fcb554e76509a0e1bc8fe7f8b0e69d6`).
- [`adapter_manifest_20tasks.json`](adapter_manifest_20tasks.json): Verified structural metadata for the 5 real LoRA adapters, including Safetensors header sizes, tensor shapes, SHA-256 hashes, and memory sizes.
- [`workplace20_coverage.json`](workplace20_coverage.json): Projected retention and request counts across context length limits (8k, 16k, 32k) with a 32-token output reservation:
  - 8,192 limit: 124 requests retained out of 622 examined (~20.0% retention).
  - 16,384 limit: 202 requests retained (~32.5% retention).
  - 32,768 limit: 402 requests retained (~64.6% retention).
