# Data Directory

This directory stores intermediate synthetic workloads, external agent trajectory datasets, and constructed replay traces. Large datasets and runtime-generated traces are ignored by Git (`.gitignore`).

## Directory Layout

- `workloads.jsonl`: Synthetic fixed-length tokenized prompts generated by `scripts/real/generate_workloads.py`. Used for prefill benchmarking and offline generation tests.
- `theagentcompany-experiments/`: (External, not tracked) Raw clone of TheAgentCompany task trajectories. Contains `.json.gz` trajectory recordings across benchmark tasks.
- `agent_replay_20tasks/`: Reconstructed multi-turn replay sequences generated by `scripts/workplace/build_workplace_replay.py`:
  - `replay_8192.jsonl`: Workload bounded to 8k context length.
  - `replay_16384.jsonl`: Workload bounded to 16k context length.
  - `replay_32768.jsonl`: Workload bounded to 32k context length.
  - `coverage.json`: Summary coverage statistics reporting examined vs. retained requests per task and LoRA adapter role.

## Generating Data

### Synthetic Workloads
```bash
python scripts/real/generate_workloads.py \
    --tokenizer models/base \
    --lengths 128 256 512 1024 2048 4096 8192 \
    --output data/workloads.jsonl
```

### Workplace Replay Traces (Requires external traces)
```bash
python scripts/workplace/build_workplace_replay.py \
    --manifest reports/real-workloads/theagentcompany_20tasks_verified.json \
    --source-repo data/theagentcompany-experiments \
    --tokenizer models/base \
    --output-dir data/agent_replay_20tasks
```
